# Día 11–12 — Mobile: Appium ⚪

- Arquitectura: Appium server, drivers (UiAutomator2 Android, XCUITest iOS), W3C.
- Appium Inspector para explorar el árbol de elementos.
- Android Studio + emulador. Xcode + simulador (si hay Mac).
- Locators nativos: `accessibility id` (el mejor), `id`, `class chain` en iOS.
- Gestos: swipe, scroll, long press. Native vs hybrid vs webview (cambio de contexto).
- Reutilización de código entre plataformas (~70%).
